# Outdoor Systems Marketplace - Full Web Structure

## 1. Public Website
- **Homepage** (Existing: SCREEN_6)
- **Product Categories**: Grid view of categories like Pergolas, Glass Systems, etc.
- **Product Detail**: Technical specs, gallery, and "Start Project" CTA.
- **Manufacturer Directory**: Searchable list of all verified companies.
- **Manufacturer Profile**: Portfolio, reviews, service areas.
- **Projects / Inspiration**: Visual gallery of completed installations.
- **Price Guides**: Educational content on cost factors.
- **About / How It Works / Contact**: Brand and support pages.
- **Login / Register**: Auth flows.

## 2. Customer Application
- **Customer Dashboard**: Overview of active projects and messages.
- **My Projects**: List of all created project configurations.
- **Create Project** (Existing: SCREEN_4)
- **Project Detail**: View specific configuration and status.
- **Offer Results / Comparison** (Existing: SCREEN_2)
- **Request Status / Messages**: Interaction with manufacturers.

## 3. Manufacturer Application
- **Manufacturer Dashboard** (Existing: SCREEN_5)
- **Requests / Request Detail**: Lead management.
- **Products / Pricing / Price Rules**: Configurator management tools.
- **Service Areas / Calendar / Portfolio**: Profile management.

## 4. Super Admin
- **Admin Dashboard**: System-wide KPIs (revenue, active users, verification queue).
- **Manufacturer Verification**: Approval workflow for new companies.
- **System Settings / CMS / SEO**: Platform management.
